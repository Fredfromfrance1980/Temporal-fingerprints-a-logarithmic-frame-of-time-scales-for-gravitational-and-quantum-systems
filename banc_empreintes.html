Banc des empreintes temporelles

Choisis un système ou règle masse, distance et horloge observée. Le banc calcule son empreinte (TP, TG, TC, Tobs et, pour une particule quantique, le temps de Compton réduit TQ) et la place sur les trois cartes du papier « Empreintes temporelles ».

Systèmes de l'atlas

Particules en superposition

Système

Pour une orbite, le rapport au calque KT = Tobs/TKepler n'est un test que si R et M sont mesurés indépendamment de Tobs.

Durée de superposition : Tobs. Branches séparées verticalement dans le champ g = GM/R² du système. Les écarts de temps propre affichés sont des majorants.

—

Carte 1 · plan des horloges (X, O)

Figure centrale du référentiel. Droite pleine : calque de Kepler O√X = 2π ; tiretée : horloge d'onde gravitationnelle, O√X = π. Points : systèmes de l'atlas munis d'une horloge.

Carte 2 · plan (X, Y)

Seuils : R < rs (X = 1/2), dernière orbite stable (X = 1/6), masse de Planck (Y = 1), longueur de Planck (XY = 1), longueur de Compton réduite (XY² = 1). Ce plan est l'image affine du diagramme masse–taille.

Carte 3 · quadrants quantiques

φG : auto-gravité de la superposition. φhorloge : temps propre lisible par l'horloge interne. Faire varier Δx déplace le point sur une droite de pente −1 ; le quadrant Q4 n'est accessible que si Tobs ≥ Y·√(Thorloge·Tg).

Formules : TC = R/c, TG = GM/c³, TP = √(ħG/c⁵), TQ = ħ/(mc²) ; X = TG/TC, Y = TP/TG, O = Tobs/TC. Identités : TG·TQ = TP², XY = LP/R, XY² = λ̄C/R, X²Y = g/aP, Kepler O√X = 2π. Facteurs de temps propre dans l'interprétation de Schwarzschild. Constantes CODATA 2022. Points de fond : atlas temporel du papier (33 systèmes, sources dans atlas_temporel.csv).
